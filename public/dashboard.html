About TapTrack

TapTrack is an RFID-based attendance system designed to simplify student attendance tracking. Using ESP32, RFID technology, and a web-based admin dashboard, it ensures accuracy and efficiency in recording attendance. Features include real-time tracking, email notifications, and a user-friendly admin interface.
